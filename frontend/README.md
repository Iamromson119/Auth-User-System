# Authentication System (Full Stack)

A secure user authentication system built using Node.js, Express, MongoDB, bcrypt and JWT.

## Features
- User registration
- Secure password hashing
- User login
- JWT based authentication
- MongoDB database
- Frontend login and register UI

## Tech Stack
- Frontend: HTML, CSS, JavaScript  
- Backend: Node.js, Express  
- Database: MongoDB  
- Security: bcrypt, JWT  

## How to Run

### Backend
```bash
npm install
node server.js
